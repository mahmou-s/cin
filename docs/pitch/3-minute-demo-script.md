# 3-minute demo script
0:00–0:30 — Submit a capability with demo evidence using the submitter token.
0:30–1:00 — Open Review Queue; show the derived source key and explicitly confirm or replace it.
1:00–1:30 — Review with a different reviewer token; show raw confidence, gated score, and gate reasons.
1:30–2:00 — Show the outbox event moving through Redis to the Neo4j projection.
2:00–2:30 — Run opportunity discovery from PostgreSQL-verified assertions and show C01 → C10 → C06 → C02.
2:30–3:00 — Show governance controls: authentication, self-review prevention, audit trail, and the fact that AI proposes opportunities rather than creating truth.
