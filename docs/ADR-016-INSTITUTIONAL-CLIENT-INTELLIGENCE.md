# ADR-016 — Institutional Client Intelligence Profiles

## Status
Accepted — planned implementation.

## Decision
CIN will adapt its questions, vocabulary, evidence requirements, risk lenses, scenarios and reports to the client's institutional archetype.

## Initial archetypes
Asset Manager, Pension Fund, Insurance, Bank, Family Office, Corporation, Government/Official Institution, Foundation, Healthcare Institution, University, SME, Family Business, Community/Regional Development Organization.

## Principle
The profile is not a score. It is a routing/context layer for the intelligence workflow.

## Data separation
Client classification must remain distinct from inferred personal attributes. The system should use explicit organization-provided context wherever possible.
